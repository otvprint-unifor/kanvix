# Kanvix

Sistema Kanban moderno desenvolvido com Next.js, TypeScript e TailwindCSS.

## Deploy

Acesse o projeto online:
https://kanvix-eight.vercel.app/

## Tecnologias

- Next.js
- TypeScript
- TailwindCSS
- DnD Kit
- SonarCloud
- Vercel

## Funcionalidades

- Criar tarefas
- Editar tarefas
- Excluir tarefas
- Drag and Drop
- Tema Dark/Light
- Filtro de prioridades
- Persistência com LocalStorage

## Qualidade de Código

- ESLint
- Lighthouse
- SonarCloud
- GitHub Actions CI
